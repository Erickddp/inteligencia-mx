# CMX-CC · Artículo 883

Ley: Código Civil para el Distrito Federal (CMX-CC)

ARTICULO 883.- Si el tesoro se buscare con consentimiento del dueño del fundo, se observarán las estipulaciones que se hubieren hecho para la distribución; y si no las hubiere, los gastos y lo descubierto se distribuirán por mitad.
