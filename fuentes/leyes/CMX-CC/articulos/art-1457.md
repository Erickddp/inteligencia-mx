# CMX-CC · Artículo 1457

Ley: Código Civil para el Distrito Federal (CMX-CC)

ARTICULO 1457.- Si el testador concede expresamente la elección al legatario, éste podrá, si hubiere varias cosas del género determinado escoger la mejor, pero si no las hay sólo podrá exigir una de mediana calidad o el precio que le corresponda.
