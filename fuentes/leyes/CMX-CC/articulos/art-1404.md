# CMX-CC · Artículo 1404

Ley: Código Civil para el Distrito Federal (CMX-CC)

ARTICULO 1404.- Si el que lega una propiedad le agrega después nuevas adquisiciones, no se comprenderán éstas en el legado, aunque sean contiguas, si no hay nueva declaración del testador.
