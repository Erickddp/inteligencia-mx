# CMX-CC · Artículo 1357

Ley: Código Civil para el Distrito Federal (CMX-CC)

ARTICULO 1357.- Si la condición se hubiere cumplido al hacerse el testamento ignorándolo el testador, se tendrá por cumplida, mas si lo sabía, sólo se tendrá por cumplida si ya no puede existir o cumplirse de nuevo.
