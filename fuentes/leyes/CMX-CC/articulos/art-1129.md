# CMX-CC · Artículo 1129

Ley: Código Civil para el Distrito Federal (CMX-CC)

ARTICULO 1129.- Si los predios entre los que está constituída una servidumbre legal, pasan a poder de un mismo dueño, deja de existir la servidumbre; pero separadas nuevamente las propiedades, revive aquélla, aun cuando no se haya conservado ningún signo aparente.
