# CMX-CC · Artículo 1107

ARTICULO 1107.- Si fuere indispensable para construir o reparar algún edificio pasar materiales por predio ajeno o colocar en él andamios u otros objetos para la obra, el dueño de este predio estará obligado a consentirlo, recibiendo la indemnización correspondiente al perjuicio que se le irrogue.
