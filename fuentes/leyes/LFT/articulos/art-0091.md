# LFT · Artículo 91

Ley: Ley Federal del Trabajo (LFT)
Ubicación: Titulo TERCERO · Condiciones de Trabajo / Capitulo VI · Salario mínimo
Texto según: Cámara de Diputados, última reforma DOF 2026-05-14 · https://www.diputados.gob.mx/LeyesBiblio/pdf/LFT.pdf
Cotejado con el DOF: NO (no se firma ningún parámetro que cite este artículo)

Artículo 91.- Los salarios mínimos podrán ser generales para una o varias áreas geográficas de aplicación, que pueden extenderse a una o más entidades federativas o profesionales, para una rama determinada de la actividad económica o para profesiones, oficios o trabajos especiales, dentro de una o varias áreas geográficas.

_Artículo reformado DOF 21-01-1988_
