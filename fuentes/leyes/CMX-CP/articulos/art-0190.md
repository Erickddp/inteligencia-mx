# CMX-CP · Artículo 190

Ley: Código Penal para el Distrito Federal (CMX-CP)

ARTÍCULO 190.- Las penas previstas para los artículos 189 y 189 bis se agravarán hasta en una mitad, si se emplea violencia física o moral.
